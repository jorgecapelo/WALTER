WALTER, by Jorge Capelo (jorge.capelo@gmail.com, Lisbon, Portugal), is a prototype. The bioclimatic thresholds are good but still approximate; it is work in progress. Be aware of this limitation if you decide to use it for more than plotting diagrams.
The way to input a location is any name that can be found on OpenStreetMap. Source file or copy the code to RStudio. The prompt is climate_diagram(\"City, Country\"), although, if there are no doubts, you can skip the country. 
The code can be used and edited freely, but please cite the authorship of the original code. 
Disclaimer: I used an LLM (Claude) as an aid in coding, threshold refinement checking against real-world data (not Wordlclim), and some geographic operations.
